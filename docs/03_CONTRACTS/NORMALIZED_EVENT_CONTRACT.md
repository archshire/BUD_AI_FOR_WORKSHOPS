# NORMALIZED_EVENT_CONTRACT

## Status

Draft contract for Bud AI MVP implementation.

## Contents

- [Event Envelope](#event-envelope)

- [Required Payloads](#required-payloads)
- [Shared Types](#shared-types)
- [Adapter Rules](#adapter-rules)

This contract defines platform-independent events entering Bud AI Core. LiveKit, Zoom, or future adapters must translate platform-specific objects into these events before core reasoning.

## Event Envelope

```ts
type NormalizedEvent = {
  event_id: string;
  workshop_id: string;
  source: "livekit" | "zoom" | "meet" | "manual" | "system" | "bud_ai";
  type: NormalizedEventType;
  occurred_at: ISODateTime;
  received_at: ISODateTime;
  actor?: ActorRef;
  privacy_scope: PrivacyScope;
  language?: LanguageCode;
  payload: EventPayload;
  trace?: {
    platform_event_id?: string;
    correlation_id?: string;
    parent_event_id?: string;
  };
};
```

## Required Payloads

### participant_utterance

Streaming or partial voice transcript event.

```ts
type ParticipantUtterancePayload = {
  transcript_fragment: string;
  is_final_fragment: boolean;
  stt_provider?: string;
  stt_confidence?: number;
  audio_track_id?: string;
};
```

### utterance_completed

Meaningful utterance boundary. Translation and deeper reasoning should generally begin here, not on every fragment.

```ts
type UtteranceCompletedPayload = {
  utterance_id: string;
  original_text: string;
  original_language: LanguageCode;
  completion_reason: "silence" | "punctuation" | "turn_change" | "manual_send" | "timeout" | "adapter_signal";
  source_event_ids: string[];
};
```

### translation_completed

```ts
type TranslationCompletedPayload = {
  utterance_id: string;
  original_text: string;
  original_language: LanguageCode;
  translated_text: string;
  target_language: LanguageCode;
  provider?: string;
  confidence?: Confidence;
  context_event_ids: string[];
};
```

### participant_message / peer_message

```ts
type TextMessagePayload = {
  message_id: string;
  text: string;
  language: LanguageCode;
  group_id?: GroupId;
  reply_to_event_id?: string;
};
```

### facilitator_instruction

```ts
type FacilitatorInstructionPayload = {
  instruction_id: string;
  text: string;
  target: "room" | "group" | "participant";
  target_id?: string;
  language: LanguageCode;
};
```

### source_pack_activated

Records the facilitator-approved Source Pack version that becomes shared
grounding context for the workshop.

```ts
{
  source_pack_id: string;
  version: number;
  material_ids: string[];
  activation_scope: "workshop_shared";
}
```

Source material retrieval may be referenced by `context_event_ids` and
`EvidenceRef.source_location_refs`; extracted content is not silently mixed
with private learner context.

### participant_correction

```ts
type ParticipantCorrectionPayload = {
  corrected_event_id: string;
  correction_type: "stt" | "translation" | "interpretation" | "state";
  corrected_text?: string;
  explanation?: string;
};
```

### participation_observation

Observable participation signal generated by the application, adapter, or facilitator tools. This event may support an adaptive check-in, but it must not be treated as evidence of motivation, personality, disengagement, or misunderstanding by itself.

```ts
type ParticipationObservationPayload = {
  participant_id: ParticipantId;
  observation_type: "low_observable_activity" | "interaction_interrupted" | "returned_after_gap" | "active_contribution";
  window_seconds: number;
  observable_counts?: {
    messages?: number;
    utterances?: number;
    reactions?: number;
    tool_actions?: number;
  };
  context_event_ids: string[];
};
```

### comprehension_check_response

```ts
type ComprehensionCheckResponsePayload = {
  checkin_id: string;
  recap_point_id: string;
  response: "green" | "yellow" | "red";
};
```

No response remains `unknown` in participant state; adapters must not create a green, yellow, or red event on a participant's behalf.

### permission_request

```ts
type PermissionRequestPayload = {

  requested_scope: "share_private_raw" | "share_private_summary" | "contact_private" | "facilitator_view";
```

```ts
type PermissionResponsePayload = {
```

## Shared Types

```ts
type ISODateTime = string;
type LanguageCode = string;
type ParticipantId = string;
type GroupId = string;
type PrivacyScope = "public_shared" | "group_shared" | "private_participant_ai";

type ActorRef = {
  actor_type: "participant" | "facilitator" | "bud_ai" | "system";
  participant_id?: ParticipantId;
};

type Confidence = {
  level: "unknown" | "low" | "medium" | "high";
  rationale: string;
  evidence_refs: EvidenceRef[];
};

type EvidenceRef = {
  event_id: string;
  item_id?: string;
};
```

## Adapter Rules

- Core reasoning must never depend on LiveKit or Zoom-specific object shapes.
- Adapters must preserve participant attribution where available.
- Adapters must preserve original language evidence.
- Partial speech events may be frequent; semantic reasoning should usually wait for `utterance_completed`.
- Translation, interpretation, and correction events must remain distinguishable.

## Open Decisions

- Exact turn-completion thresholds.
- STT provider and confidence normalization.
- Translation provider and prompting/context strategy.
- Adapter-specific retry and ordering behavior.
